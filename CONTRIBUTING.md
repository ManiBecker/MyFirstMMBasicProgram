# Contributing

Thank you for your interest in contributing to **My First MMBasic Program**!

Whether you are a beginner or an experienced MMBasic programmer, your contributions are welcome. Every improvement helps make this tutorial more useful for the community.

## How You Can Help

There are many ways to contribute:

* Report mistakes or unclear explanations
* Fix spelling or grammar
* Improve the English wording
* Suggest better examples
* Submit new example programs
* Report compatibility issues
* Improve the documentation

Even small improvements are valuable.

## Before You Start

Please check the existing issues before creating a new one. If you would like to work on a larger feature or write a new chapter, consider opening an issue first so we can discuss the idea.

## Style Guidelines

Please keep contributions:

* Beginner-friendly
* Easy to understand
* Well commented
* Focused on one topic at a time

Avoid overly complex examples if a simpler solution teaches the same concept.

## MMBasic Programs

Example programs should:

* Be easy to read
* Use meaningful variable names
* Include comments where appropriate
* Run without modification whenever possible

Examples should preferably work on both:

* PicoMite
* Colour Maximite 2

If a program is hardware-specific, please mention this clearly.

## Documentation

Documentation is written in **AsciiDoc**.

Please:

* Keep the writing concise.
* Use correct English.
* Explain *why* something is done, not only *how*.

## Pull Requests

If you would like to contribute a specific change, you can [create a pull request](https://github.com/ManiBecker/MyFirstMMBasicProgram/pulls).

Before submitting a pull request, please make sure that:

* The example has been tested.
* The documentation is updated if necessary.
* The changes remain beginner-friendly.
