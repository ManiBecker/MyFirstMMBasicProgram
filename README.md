# MyFirstMMBasicProgram
A step-by-step introduction to MMBasic programming for beginners using the PicoMite and Colour Maximite.

This project is an English translation of the German tutorial "[MeinErstesMMBasicProgramm](https://github.com/ManiBecker/MeinErstesMMBasicProgramm)".

It is intended for beginners who want to learn MMBasic on the
PicoMite or Colour Maximite.

The tutorial starts with the very first program and gradually
introduces the language using many practical examples.

## Features

- Beginner friendly
- Step-by-step explanations
- Complete example programs
- Works with PicoMite and Colour Maximite
- Written in AsciiDoc
